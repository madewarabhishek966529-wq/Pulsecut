# Screen 4: Export dialog

Design an export dialog (560px, glass panel).

Contents:
- Preview thumbnail of the project with duration chip.
- Settings: Resolution (720p, 1080p, 4K disabled with "Soon" tag), Frame rate (24, 30, 60), Format (MP4), Quality (Fast, Balanced, Best).
- Estimated file size and time in mono text.
- Primary "Export video" button.
- Progress state: gradient progress bar with percent, "Rendering frame 214 of 360", Cancel button.
- Done state: success check with pulse glow, Download button, Copy link, Share row.
