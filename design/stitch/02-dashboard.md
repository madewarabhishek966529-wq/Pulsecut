# Screen 2: Dashboard

Design the project dashboard for "Pulsecut".

Layout:
- Left rail (72px): logo, icons for Projects, Templates, My Effects, Settings, and a user avatar at the bottom.
- Header: greeting "Your projects", search field, sort dropdown, and a gradient "New Project" button.
- A hero strip: "Try Prompt-to-Filter" card with a short animated-looking gradient, an input "Describe a filter... e.g. melting neon VHS" and a Generate button.
- Project grid: 4 columns of cards with 4:5 thumbnails, title, "Edited 2h ago", duration chip, and a hover state showing Open / Duplicate / Delete icons.
- Include one skeleton-loading card and an empty state variant (illustration-free: line icon, "No projects yet", "Create your first edit" button).
